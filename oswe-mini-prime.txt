## How to run locally ⚡
1. Clone or copy the project folder to your machine (or simply keep the files in one folder).
2. Open `index.html` in a modern browser (Chrome / Edge / Firefox) — no server required.

Optional (Windows) path example:
- Double-click `index.html` or drag it onto your browser window.

---

## Keyboard & Accessibility 🎯
- Cards are focusable (tab) and open on Enter.
- Press `Escape` to close the detail panel.
- Click outside the panel to close it.
- Buttons include `aria-pressed` and the panel uses `aria-hidden`.

---

## Implementation details — where things are in the code 🔎

- Dataset:
  - Generated inside `script.js` at the top in `ZODIACS` array.
  - Each object contains:
    - `en`, `cn`, `icon`, `element`, `trait`, `trait_cn`, `keywords`, `summary_en`, `summary_cn`.
  - Edit these directly to change the data.

- State & LocalStorage:
  - Keys used:
    - `zodiac_lang` — store the language ('en' | 'cn')
    - `zodiac_theme` — store the theme ('light' | 'dark')
    - `zodiac_filter` — store the element filter
  - Updated on user changes, and restored on page load.

- UI text & translations:
  - Basic UI strings are in `UI_TEXT` object inside `script.js`.
  - Language toggle updates placeholder, button labels and the detail panel.

- Filtering & Search:
  - `searchInput` filters by English/CN name and keywords instantly as you type.
  - Element dropdown filters by element string (EN element names in dataset).
  - Filtering is client-side and creates quick DOM updates.

- Animations:
  - CSS transitions for card hover and slide-in panel.
  - Subtle glow animations added to the detail panel and card backgrounds.
